# Harper website concepts

Design concepts by Second Shift for Harper Health Network. Not the live site.

- `index.html`: password page and the list of versions.
- `round-4/`: The Refresh, closest to the current site.
- `round-3/`: Local Editorial.
- `round-1/`, `round-2/`: earlier rounds, three options each.
- `story/`: The Harper Story, an animated concept made by a friend of Second Shift. The character is renamed from Luis to Harper.
- `assets/hub.js`: a light password check and the "All versions" button on every page. It is not real security: the files in this repo are public.

People in the photos are stand-ins (Unsplash). Replace them with real DFW customers and providers before launch.
